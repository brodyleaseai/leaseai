# OCR Fallback System for LeaseAI

## Overview

The LeaseAI OCR fallback system automatically detects scanned or image-based PDF leases and extracts text using industry-leading OCR engines. This ensures that **all** lease documents—digital or scanned—can be processed reliably.

## How It Works

### Automatic Detection & Fallback

### OCR Engine Selection

1. **AWS Textract** (Primary OCR)
   - **Quality**: Industry-leading accuracy (99.5%+ on standard documents)
   - **Speed**: ~2-5 seconds per page
   - **Cost**: $1.50 per 1,000 pages (~$0.075 for a 50-page lease)
   - **Requirements**: AWS account + credentials configured
   - **Best for**: Production, high-volume processing

2. **Tesseract OCR** (Fallback)
   - **Quality**: Good accuracy (90-95% on clear scans)
   - **Speed**: ~3-10 seconds per page
   - **Cost**: Free (open source)
   - **Requirements**: Local Tesseract installation
   - **Best for**: Development, testing, AWS unavailable

## Installation

### 1. Install Python Dependencies

```bash
pip install -r requirements_ocr.txt
```

This installs:
- `boto3` - AWS SDK for Textract
- `pdf2image` - PDF to image conversion
- `pillow` - Image processing
- `pytesseract` - Tesseract wrapper

### 2. Install System Dependencies

#### Ubuntu/Debian
```bash
sudo apt-get update
sudo apt-get install tesseract-ocr poppler-utils
```

#### macOS
```bash
brew install tesseract poppler
```

#### Windows
1. Download Tesseract: https://github.com/UB-Mannheim/tesseract/wiki
2. Download Poppler: https://github.com/oschwartz10612/poppler-windows/releases/
3. Add both to system PATH

### 3. Configure AWS Textract (Optional, Recommended)

#### Option A: Environment Variables
```bash
export AWS_ACCESS_KEY_ID="your-access-key"
export AWS_SECRET_ACCESS_KEY="your-secret-key"
export AWS_REGION="us-east-1"
```

#### Option B: Update `config.py`
```python
AWS_REGION = "us-east-1"
AWS_ACCESS_KEY_ID = "your-access-key"
AWS_SECRET_ACCESS_KEY = "your-secret-key"
```

#### Option C: AWS CLI (automatically detected)
```bash
aws configure
```

**Note**: If AWS credentials are not configured, the system automatically falls back to Tesseract.

## Usage in Production

### Automatic Processing

No code changes needed! The OCR fallback is **fully automatic**:

```python
from extraction_pipeline import LeaseExtractionPipeline

pipeline = LeaseExtractionPipeline()

# Works with digital PDFs
text, pages = pipeline.extract_text_from_pdf("digital_lease.pdf")

# Automatically detects and OCRs scanned PDFs
text, pages = pipeline.extract_text_from_pdf("scanned_lease.pdf")
```

## Troubleshooting

### "Failed to initialize AWS Textract client"

**Cause**: AWS credentials not configured

**Fix**:
1. Set environment variables: `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`
2. Or run `aws configure`
3. Or update `config.py` with credentials

**Fallback**: System will use Tesseract instead

### "Failed to convert PDF to images"

**Cause**: Poppler not installed

**Fix**:
- Ubuntu: `sudo apt-get install poppler-utils`
- macOS: `brew install poppler`
- Windows: Download from https://github.com/oschwartz10612/poppler-windows/releases/

### "Tesseract not found"

**Cause**: Tesseract OCR engine not installed

**Fix**:
- Ubuntu: `sudo apt-get install tesseract-ocr`
- macOS: `brew install tesseract`
- Windows: Download from https://github.com/UB-Mannheim/tesseract/wiki

### Low quality OCR output

**Recommendations**:
1. Use AWS Textract instead of Tesseract (higher accuracy)
2. Ensure scans are at least 300 DPI
3. Pre-process images (deskew, denoise) before OCR
4. Check for encrypted/protected PDFs
