## REVISED PRIORITY: Enterprise-First Build Path

### Phase 1: Build Proprietary IP Moats (12-16 weeks)

**Goal:** Build the $24.3M in IP assets that create defensibility

#### Priority 1A: Amendment Resolution Graph™ ($5.6M IP Asset)

**Effort:** 6-8 weeks (full-time engineering)

**Components to Build:**

1. **Data Model Layer**
   - Graph database schema (Neo4j or PostgreSQL with recursive CTEs)
   - Node types: Base Lease, Amendment, Clause, Version
   - Edge types: MODIFIES, SUPERSEDES, REFERENCES, CONTROLS
   - Temporal versioning: Track effective dates for each clause version

2. **Amendment Parsing Engine**
   - AI extraction of:
     - Which clauses the amendment modifies
     - Effective date of changes
     - Conditional supersession rules
     - Cross-references to other amendments
   - Natural language processing to identify:
     - "Section 3.2 is hereby amended to read..."
     - "Notwithstanding Clause 5.1 of the Base Lease..."
     - "This Amendment supersedes Amendment #2 dated..."

3. **Clause Resolution Logic**
   - Query: "What is the current rent amount as of [date]?"
   - System traverses: Base Lease → Amendment #1 → Amendment #3 → Amendment #5
   - Returns: Controlling clause + provenance chain
   - Handle conflicts: When Amendment #4 and #5 both modify same clause

4. **Visual Interface (Graph Visualization)**
   - Interactive graph showing base lease in center
   - Amendments as connected nodes with date labels
   - Click amendment → see which clauses it modifies
   - Timeline slider: See clause history over time
   - Export: PDF visualization for client reports

5. **Query API**
   - REST API: `/lease/{id}/clause/{clause_name}?as_of={date}`
   - Returns: Current value + amendment chain + confidence score
   - Audit trail: Full provenance of every clause value

**Success Metrics:**
- Process base lease + 5 amendments in under 5 minutes
- Correctly identify controlling clause 95%+ of time
- Generate visual graph for any lease
- API response time <500ms
- Client demo: "Here's your lease's amendment history at a glance"

**Validation:**
- Test on 100 real leases with amendment chains
- Compare output to manual legal review
- Publish accuracy benchmark report

**IP Protection:**
- Document architecture in patent application
- File provisional patent before any public demos
- Trademark "Amendment Resolution Graph™"

#### Priority 1B: Build Proprietary Dataset (50,000 Leases)

**Effort:** Ongoing (24+ months to reach 50K)

**Current Status:** 0 leases collected

**Three-Phase Strategy:**

**Phase 1: Seed Dataset (Months 1-6) — Target: 1,000 Leases**

*Sources:*

   - Request historical lease portfolios from first 5-8 clients
   - Offer: "We'll process your entire portfolio for free in exchange for anonymized training data"
   - Get signed data license agreement

2. **Public REIT Filings** (300-400 leases)
   - Scrape material lease exhibits from SEC 10-K/10-Q filings
   - Public REITs: Simon Property Group, Brookfield, Oxford Properties
   - Fully legal - public documents

3. **Purchased Datasets** (300-400 leases)
   - Legal document vendors (Law360, Lexis, Westlaw)
   - CRE data providers (CoStar, CBRE Research)
   - Budget: $10K-$20K

4. **Synthetic Data Generation** (200 leases)
   - Use GPT-4 to generate realistic lease documents
   - Vary: jurisdictions, asset classes, lease structures
   - Human review for quality

*Process:*
- Manual abstraction by founder + paralegal contractors ($150/lease)
- Budget: $150,000 for 1,000 leases
- Create ground-truth labels for 85 fields per lease
- Store in private database with strict access controls

**Phase 2: Scale Dataset (Months 7-18) — Target: 10,000 Leases**

*Sources:*
1. **Paying Client Leases** (5,000+ leases)
   - Every client lease processed = training data (with permission)
   - Data license clause in SaaS agreement
   - Anonymize: Remove names, addresses, financial details

2. **Strategic Partnerships** (3,000 leases)
   - Partner with CRE law firms: "We'll abstract your closed deals for free"
   - Partner with property management firms
   - Offer: Revenue share or free tier in exchange for data

3. **Crowdsourced Abstraction** (2,000 leases)
   - Hire remote paralegal workforce (Upwork, Fiverr)
   - $50/lease for structured abstraction
   - Quality control: Multiple reviewers per lease

**Phase 3: Mature Dataset (Months 19-36) — Target: 50,000 Leases**

*Sources:*
1. **Operational Flywheel** (30,000+ leases)
   - By Year 3, processing 70 clients × 100 leases/client avg = 7,000 leases/year

   - Compounding: More clients = more data = better accuracy = more clients

2. **Data Acquisition** (10,000 leases)
   - Purchase datasets from distressed CRE data companies
   - Acquire smaller lease abstraction competitors (buy their dataset)
   - Budget: $500K from seed round

├── base_leases/          # 35,000 base lease documents

#### Priority 1C: CAM Reconciliation Module

**Effort:** 3-4 weeks

**Components:**

1. **CAM Clause Extraction**
   - AI identifies CAM provisions in abstracted lease
   - Extract: Base year, CAM caps, exclusions, pro-rata share, reconciliation deadlines

2. **Actual Cost Ingestion**
   - CSV/Excel upload: Property manager's actual operating expenses
   - Auto-map: Expense categories to lease-defined buckets
   - Flag: Expenses that fall under tenant exclusions

3. **Reconciliation Calculation Engine**
   - Calculate: Tenant's pro-rata share of actual costs
   - Compare: Estimated CAM paid vs. actual CAM owed
   - Identify: Overcharges (tenant paid too much) or undercharges (tenant paid too little)

4. **Dispute-Ready Reports**
   - Generate: Line-item reconciliation report
   - Include: Lease clause references for every calculation
   - Export: PDF report tenant can use to dispute charges

5. **Overcharge Recovery Tracking**
   - Dashboard: Total CAM overcharges recovered across all clients
   - ROI calculator: "This module has recovered $X for you this year"

**Pricing:**
- Add-on module: $500-$1,000/month
- OR: Success fee: 10-20% of recovered overcharges

**Client Value:**
- Industry estimate: $2B+ in annual CAM overcharges across North America
- Average client: 200 leases, $50K-$200K in recovered overcharges per year
- Module pays for itself on first recovered overcharge
